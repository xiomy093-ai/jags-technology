Gestión Operativa y Base de Datos

Formularios Internos

Módulo de control para registro de solicitudes, clientes, cotizaciones, órdenes de trabajo y personal autorizado.

Vista de diseño operativo. Estos formularios permiten gestionar los registros de la base de datos jags_technology. Los códigos (S001, AC001, C001…) se adaptan al formato de las tablas.

Navegación rápida entre formularios:

Solicitud Cliente Cotización Orden de trabajo Venta Garantía Asesor Técnico Proveedor Plan corporativo Asignar proveedor

Los campos marcados con * son obligatorios.

Área Comercial / Clientes

Solicitud de servicio Tabla: solicitud

Registro inicial de requerimiento del cliente. Documento y servicio requerido.

Solo números (6 a 15 dígitos). Debe estar previamente registrado.
Máximo 300 caracteres.
Se completa solo: id_solicitud (S001, S002…), estado (Pendiente), fecha_creacion (automática), id_proveedor.

Base de Clientes

Registro de cliente Tabla: cliente

Ingreso de datos generales del cliente natural o corporativo.

Se completa solo: fecha_registro (fecha actual).

Área Comercial

Cotización Tabla: cotizacion

Elaborada por el asesor comercial a partir de una solicitud aprobada.

Se completa solo: id_cotizacion (C001…), estado (Emitida), fecha_emision (hoy).

Coordinación Técnica

Orden de trabajo Tabla: orden_trabajo

Programación de la labor técnica a partir de una cotización aprobada.

Se completa solo: id_orden (OT001…), id_cliente, estado (Programada).

Área de Ventas

Venta Tabla: venta

Registro final al concluir satisfactoriamente el servicio o instalación.

Se completa solo: id_venta (V001…).

Postventa

Garantía Tabla: garantia

Registro de póliza o respaldo de garantía por venta realizada.

Se completa solo: id_garantia (G001…), id_asesor, id_tecnico, fecha_vencimiento.

Administración

Asesor comercial Tabla: asesor_comercial

Registro de personal del área comercial.

Se completa solo: id_asesor (AC001…), activo (Sí).

Administración

Técnico Tabla: tecnico

Registro de personal operativo de soporte e instalaciones.

Se completa solo: id_tecnico (T001…), activo (Sí).

Área de Compras

Proveedor Tabla: proveedor

Empresas o suministradores de equipos y materiales.

Se completa solo: id_proveedor (PV001…), activo (Sí).

Administración

Plan corporativo Tabla: plan_corporativo

Planes disponibles (Avanzado o Premium) para clientes corporativos.

Se completa solo: id_plan (PC001, PC002), activo (Sí).

Área de Compras

Asignar proveedor a una solicitud Tabla: solicitud

Vincular un proveedor a una solicitud existente que requiera insumos o equipos.

Se completa solo: Actualiza id_proveedor en la tabla de la solicitud.
